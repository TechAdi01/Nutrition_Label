# Typography Nutrition Label

## Description
This project is a **Nutrition Label Webpage** built using **HTML and CSS**. It focuses on **typography** by styling text to improve readability and layout. The project enhances skills in text styling, line height adjustments, and positioning text using CSS.

## Features
- Styled text for better readability and structure
- CSS typography techniques for font selection and spacing
- Flexible and structured layout for a nutrition label design
- Use of `font-weight`, `letter-spacing`, and `line-height` for improved text appearance

## Technologies Used
- **HTML5**
- **CSS3** (Typography styling)
- **Google Fonts** for custom typography
